## 2. Where it runs

The M10 file broker runs in the **Python runtime**, not in Electron main as the architecture sketch suggested. There are three reasons:

* the ledger and grants live in the runtime;
* S2's quarantine and placement need the same transaction as the ledger;
* S3's Windows Job Objects already exist there through `ctypes` (Node has no Job API without a native dependency).

Main stays the trusted-UI and provider boundary:

* It opens the native folder dialog **and** a native confirmation naming the permissions.
* It resolves a dropped file from its own store.
* It chooses the provider and makes the one provider call.

No absolute path crosses the renderer or model boundary in either direction.

## 3. Migration `0017`

* **`file_roots`**:
  * explicit `can_read`, `can_create` and `can_modify` (CHECK `can_modify = false`);
  * canonical path plus directory identity (volume serial, directory file index);
  * one live root per folder, enforced by a partial unique index on the case-folded path.
* **`file_refs`**: task-owned authority, either `ROOT_FILE` (root plus validated relative name) or `DROPPED_FILE` (that exact file). Each is bound to volume, index, size, `mtime_ns` and SHA-256.
* **`documents`**: bounded text (at most 120,000 characters), `document_private`, `expires_at` 24 h, purged to NULL.
* **`document_disclosures`**: UNIQUE on grant and task.
* **`document_answers`**: grounded comparison output.
* **Grant kind**: `task_grants.kind` gains `document_disclose`.
* **Downgrade**: refuses while any root or document grant exists.

`test_migration_0017` covers the shape, the database invariants and the downgrade. The older migration tests now derive head from alembic instead of hard-coding it.

## 4. Path and file safety (`app/files`)

**Name rules (`names.py`), checked before any filesystem call.** Refused:

* traversal: `..`, `.`, empty components;
* absolute, drive-relative, UNC and `\\?\` / `\\.\` / `GLOBALROOT` device paths;
* any `:` (ADS or drive);
* reserved device names, including `COM¹`, `CONIN$` and names with an extension;
* trailing dot or space;
* control and format characters;
* non-NFC names;
* over-long or too-deep paths.

**Resolution (`broker.resolve`).** An `lstat` walk from the verified root refuses any reparse point (junction, symlink, mount point) on every component.

**Handle-verified read (`broker.read_verified`).** The file is opened, and then:

* the handle's `GetFinalPathNameByHandleW` must equal the resolved path, which defeats 8.3 aliases and junction swaps after resolution;
* it must lie strictly inside the root;
* the file must have exactly one hard link;
* its identity and SHA-256 must match the ref;
* size and identity are re-checked after the bounded read.

A different file under the same name, or the same file rewritten, is `file_changed`.

**Root registration (`broker.inspect_root`).** A root must be a local, non-reparse directory. It is refused (`root_protected`) if it is, contains or sits inside Windows, Program Files (x86 and x64), ProgramData, Roaming or Local AppData, or a Lumi-owned tree (the runtime directory and the browser-profile root). It is also refused if it is, or contains, the user's profile or `C:\Users`.

The protected folders come from `SHGetKnownFolderPath`, not environment variables. Registration fails closed (`protected_folders_unknown`) unless every one resolves.

**The listing's own exclusions apply when a file is added.** Dot-directories, `AppData`, `.git`, `node_modules`, Office lock files and anything deeper than the listing are refused (`not_listable`).

**Residual (honest).** This is handle-verified access, not an operating-system sandbox. A same-user process can change a file after the verified read, and the runtime process runs with the user's full rights.

## 5. Extraction (`app/documents`)

Extraction is standard-library only, so there is no new dependency. It covers:

* **Text:** UTF-8 with or without a BOM, or UTF-16 with a BOM.
* **DOCX:** `zipfile` plus `ElementTree`.
* **PDF:** a reviewed subset: classic xref, object streams, Flate/ASCIIHex/ASCII85, literal and hex strings, `Tj`/`TJ`/`'`/`"`, `ToUnicode` `bfchar`/`bfrange`.

Anything else is refused rather than guessed.

**The helper process.** The runtime reads the verified bytes and pipes them to `python -E -s -S -m app.documents.helper --format <closed format>`:

* no path, no shell, no `site` or `.pth` processing;
* an environment carrying only `SystemRoot`;
* a Job Object that is kill-on-close, limits memory to 512 MB and allows **one process**, so the helper cannot start anything;
* a 20 s kill;
* a closed JSON result.

**Limits:**

| What | Limit |
| --- | --- |
| File size | 10 MB |
| PDF pages | 50 |
| Extracted text | 120,000 characters |
| ZIP members | 400 |
| ZIP expansion | 40 MB, ratio at most 100 |
| Decoded PDF bytes | 32 MB (8 MB per stream) |
| Nesting | 32 levels |
| Content operators | 400,000 |
| PDF scan budget | about 4× the file size |

**What is never done:**

* Macros are refused (`vbaProject`, `macroEnabled`).
* External relationships are counted and never fetched.
* Field instructions are skipped.
* PDF JavaScript, actions, URIs and embedded files are counted and never acted on.
* Encrypted PDFs are refused.
* XML parts must be UTF-8, and any DOCTYPE or ENTITY is refused.

## 6. Comparison and disclosure

**Local comparison.** It is deterministic (shared terms, terms only in one document, headings, sizes) and sends nothing.

**Provider comparison.** It needs a trusted card naming the documents, their display names, the **exact redacted excerpt** of each (at most 6 KB), the one provider and model (main's choice), and the person's typed purpose.

The trusted click activates a single-use grant. The claim consumes it and writes a UNIQUE disclosure row in one committed transaction **before** the provider is called.

The provider sees `d1`/`d2` and redacted excerpts only: no file name, folder or path. It uses the private class `document_compare`, with one recipient, zero failover and no image. The result is a closed schema; every quote must be in the excerpt it names, and every number must be in a quote. A lost result is `OUTCOME_UNKNOWN` and never repeated.

Revoking the source folder makes the document unusable for extraction, comparison, the card, confirmation and claim (`root_revoked`).

**Where extracted text goes.** Only to the `documents` row, the trusted panel (a bounded preview) and that one approved call. It never reaches memory, voice, planners, research, desktop context, task events or logs. The Python source scan and the TypeScript firewall test pin this.

**Retention.** Text is purged after 24 h. Comparison quotes, the summary and dropped-file paths expire on the same clock. The sweep runs at startup and on every read.

## 9. Independent adversarial review (fresh Claude reviewer; no external model)

Brief: escape a root; widen a dropped file; substitute a file; leak a path to a provider; trigger fetching or macros; leak text into unrelated context. **No Critical finding.** Every finding was verified by the lead against the code and fixed:

| # | Severity | Finding | Fix |
| --- | --- | --- | --- |
| 1 | Medium | Protected roots came from environment variables the runtime does not receive, so only Windows and ProgramData were protected. Lumi-owned trees were never passed in. | Known folders now come from `SHGetKnownFolderPath`, and registration fails closed unless all resolve. Profile and `C:\Users` are ancestor-refused. The runtime directory and profile root are forbidden. Regression tests run with the runtime's reduced environment. |
| 2 | Medium | A root-file reference could name files the listing hides (for example under `AppData` or `.git`). | `listable()` applies the listing's exclusions on add (`not_listable`). |
| 3 | Medium-Low | Revocation did not reach extraction in flight or an already-approved grant. | The root row is locked and re-checked in `extract`'s final transaction. `_text` (used by compare, card, confirm and claim) refuses `root_revoked`. |
| 4 | Low | A UTF-16 DOCX part hid `<!DOCTYPE` from the byte scan. | Parts must be UTF-8 (no NUL, no UTF-16 BOM, UTF-8 declaration only). |
| 5 | Low | A corrupt ZIP in sniffing could raise a 500; sniffing ran on the event loop. | Any parser surprise is `zip`, so the file is refused; sniffing runs in a thread; the member count is capped. |
| 6 | Low | Unterminated strings made PDF scanning quadratic (contained by the 20 s kill). | Refuse on the first unterminated object, plus a global scan budget. |
| 7 | Low | Retention: comparison quotes and dropped paths were kept forever, and the purge ran only at startup. | Retention now covers both, and the sweep also runs on reads. |
| 8 | Low | CREATE came from a renderer checkbox only. | A native confirmation in main names the permissions. |
| 9 | Info | The helper processed `site` and `.pth` files. | The helper now runs with `-S`. |

**Documented, not changed.** The helper has no network sandbox beyond code-level stdlib-only imports and the one-process job. `registerDroppedFile` accepts a renderer-supplied path; this is pre-existing, and it now also gates reading. The listing has a benign TOCTOU (names only; reads remain refused).

## 11. Residual risks

* Handle-verified reads, not a sandbox.
* The PDF subset refuses PDFs without a `ToUnicode` map for composite fonts, and image-only scans.
* Redaction reduces identifiers; it is not anonymisation.
* A dropped path is only as trustworthy as main's dropped-file registration.
* No production-signed installed validation exists.
